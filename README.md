# Inside Turing — RT Cores, INT8/INT4 Tensor Cores, GDDR6

A low-level look at NVIDIA's 2018 Turing architecture: TU102/104/106 RTX dies and the RT-less TU116/117 budget dies. Block diagrams, the Turing SM with 1st-gen RT cores, 2nd-gen tensor cores supporting INT8 (215 TOPS) and INT4 (430 TOPS), TSMC 12FF process, GDDR6 mainstream memory, NVLink 2.0 bridge connector, and the Tesla T4 75 W inference card that defined cloud GPU economics for years. Includes an interactive Turing SKU picker.
